# EDF DIGIT — Générateur de documents structurés

## Présentation en une phrase
Outil interne pour rédiger, relire et télécharger des procédures techniques sous forme de documents structurés DIGIT, directement dans le navigateur.

## Public visé
Les personnes qui préparent ce type de procédure dans un cadre interne. Les modèles proposés portent sur l’installation de caméras, le paramétrage d’adresses IP, les comptes administrateur, les mises à jour de firmware et les flux vidéo. L’unité ou l’équipe utilisatrice n’est pas nommée dans le code : À confirmer.

## Problème résolu
Produire un document homogène — page de garde, historique des versions, niveau d’accessibilité, listes de diffusion, sections numérotées, étapes illustrées et annexes — puis le récupérer en fichier, sans compte ni serveur.

## Fonctionnalités principales
- Créer un document vierge ou partir d’un modèle de procédure déjà structuré.
- Compléter l’en-tête, l’historique, la diffusion, les sections et les annexes, et y joindre des images.
- Afficher un aperçu du document mis en page.
- Télécharger le résultat en fichier Word, en page HTML ou en fichier de données JSON.
- Retrouver, copier et supprimer les brouillons, qui restent enregistrés dans le navigateur utilisé.

## Statut
En développement.

La version indiquée dans le projet est 0.0.0. L’application se lance en local et couvre la rédaction, l’aperçu et trois formats de téléchargement. Elle n’est reliée à aucun service en ligne : les documents ne quittent pas le navigateur. L’export PDF n’existe pas. Le nombre de pages et le nombre d’annexes se saisissent à la main. Le rappel concernant DOCTEAM est un texte du modèle, pas une liaison avec cet outil.
